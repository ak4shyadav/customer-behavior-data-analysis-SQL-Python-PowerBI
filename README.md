# 📊 Customer Behavior Data Analyst Portfolio Project

## Overview

This project demonstrates a complete, industry-standard, end-to-end **data analytics workflow** designed to mirror real-world responsibilities of professional data analysts. It focuses on analyzing **customer shopping behavior** using SQL, Python, and Power BI to extract meaningful insights that support **business decision-making**.

The objective of this project is to transform raw retail data into **actionable business insights** through structured analysis, visualization, and reporting.

---

## Business Problem

Retail businesses often struggle to understand:

* What drives customer purchasing behavior?
* Which customer segments generate the most revenue?
* How do shopping patterns vary across time, categories, and demographics?
* What factors influence repeat purchases and loyalty?

This project addresses these questions by analyzing transactional customer data and uncovering patterns that can help improve:

* Revenue growth
* Customer retention
* Product strategy
* Marketing effectiveness

---

## Objectives

* Perform data cleaning, transformation, and validation
* Conduct exploratory data analysis (EDA)
* Write optimized SQL queries for business questions
* Generate KPIs and performance metrics
* Build an interactive Power BI dashboard
* Communicate insights through reports and presentations

---

* **SQL** – Data querying and aggregation
* **Python (Pandas, NumPy, Matplotlib, Seaborn)** – Data cleaning, EDA, analysis
* **Power BI** – Interactive dashboards and visual reporting
* **Jupyter Notebook** – Analytical workflow documentation
* **Excel/CSV** – Raw data handling
* **GitHub** – Version control and project documentation

## Dataset

The dataset consists of customer shopping behavior records including:

* Customer demographics
* Purchase history
* Product categories
* Transaction values
* Frequency of purchases

The raw dataset is provided in CSV format.

## Project Workflow

### 1. Data Understanding

* Reviewed dataset structure
* Identified missing values and inconsistencies
* Understood variable distributions

* Handled missing values
* Removed duplicates
* Standardized column formats
* Created derived features

### 3. Exploratory Data Analysis (EDA)

* Identified purchasing trends
* Analyzed customer segments
* Visualized frequency distributions
* Detected outliers and anomalies

### 4. SQL Analysis

* Created business-focused queries
* Calculated KPIs
* Performed aggregations and joins
* Extracted trend-based insights

### 5. Dashboarding (Power BI)

* Built an interactive dashboard
* Visualized KPIs
* Created filters for dynamic analysis
* Designed executive-level visuals

### 6. Reporting & Presentation

* Compiled insights into PDF and PPT
* Created business-friendly narratives
* Highlighted key findings
